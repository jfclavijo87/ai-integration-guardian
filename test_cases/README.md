# Batería de casos de AI Integration Guardian

Los seis casos son sintéticos y representan iniciativas de una pyme industrial. Cada carpeta contiene:

- `caso.txt`: documento que se carga en Guardian.
- `resultado_esperado.json`: verdad de referencia definida antes de ejecutar el agente.

## Casos completos

1. Inspección visual de defectos en piloto.
2. Mantenimiento predictivo en prueba de concepto.
3. Planificación de demanda en fase de idea.

## Casos con defecto sembrado

4. Derecho de uso del dato no acreditado.
5. Beneficio prometido sin línea base.
6. Proyecto sin responsable personal del resultado.

Los resultados esperados no fueron generados por el modelo evaluador. Constituyen la referencia contra la que se compararán las salidas.
